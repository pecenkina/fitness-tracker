# Fitness Tracker

Персональный фитнес-трекер в формате PWA: журнал тренировок, анализ прогресса, каталог упражнений и планы занятий.

## Статус

Проект на этапе проектирования. Исходный код приложения ещё не реализован.

## Основные возможности MVP

- Регистрация и вход по email.
- Профиль пользователя и тренировочная цель.
- Локальный каталог упражнений с фильтрами.
- Создание тренировок вручную и по сохранённому плану.
- Журнал тренировок и история упражнений.
- Дашборд с прогрессией весов и распределением нагрузки.
- Устанавливаемый PWA-интерфейс.

## Дальнейшее развитие

OAuth-вход, интеграции с несколькими фитнес-сервисами, показатели активности (шаги, пульс, калории, SpO₂ при доступности), расширенная аналитика на Python и FatSecret.

## Выбранный технологический стек

| Компонент | Технология |
| --- | --- |
| Frontend | React + TypeScript |
| Сборка frontend | Vite |
| PWA | Web App Manifest + Service Worker |
| Интерактивные графики | Recharts |
| Backend | Node.js + Express.js (JavaScript) |
| Работа с БД | `pg` (node-postgres), параметризованные SQL-запросы без ORM |
| База данных | PostgreSQL |
| Аналитика в MVP | SQL + JavaScript |
| Аналитика после MVP | Python + Pandas + FastAPI (при необходимости) |
| Развёртывание | Docker Compose (позже) |

Python не требуется для базовой аналитики MVP. После реализации журнала и графиков может быть добавлен отдельный аналитический сервис. Графики в браузере по-прежнему строятся через Recharts.

## Структура репозитория

- `frontend/` — React + TypeScript PWA (планируется).
- `backend/` — Express API на JavaScript (планируется).
- `docs/` — требования и план разработки.
- `analytics/` — модуль Python, **только после MVP**, если потребуется.
