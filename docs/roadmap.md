# План разработки Fitness Tracker

## Этап 1 — MVP

- [ ] Проектирование схемы PostgreSQL, SQL-запросов и REST API.
- [ ] Инициализация frontend (React + TypeScript + Vite + PWA).
- [ ] Инициализация backend (Node.js + Express.js на JavaScript).
- [ ] Подключение PostgreSQL через `pg`, параметризованные SQL-запросы и SQL-миграции без ORM.
- [ ] Регистрация, вход и профиль.
- [ ] Каталог упражнений и фильтры.
- [ ] Создание тренировок, подходов и журнал.
- [ ] Шаблоны и запуск тренировок по планам.
- [ ] Базовая аналитика на SQL и JavaScript: максимальные веса, тренировочный объём, нагрузка на мышцы.
- [ ] Интерактивные графики на React с использованием Recharts.
- [ ] Проверка адаптивности, авторизации и установки PWA.

## Этап 2 — интеграции и расширенная аналитика (после MVP)

- [ ] OAuth/OIDC-вход.
- [ ] Выбор первого фитнес-провайдера по доступности API.
- [ ] Импорт показателей активности и контроль повторов.
- [ ] При наличии задач, требующих более сложных расчётов, добавить Python + Pandas, при необходимости — FastAPI для отдельного аналитического сервиса.
- [ ] Расширенная аналитика: тенденции, сравнение периодов, анализ динамики нагрузки.

## Этап 3 — дальнейшее развитие

- [ ] Дополнительные фитнес-провайдеры.
- [ ] Офлайн-синхронизация тренировок.
- [ ] FatSecret и учёт питания.
- [ ] Расширенные персональные рекомендации.

Python не используется для первичного построения графиков в интерфейсе: данные агрегируются в PostgreSQL и/или JavaScript и передаются в React + Recharts. Подключение Python планируется только после реализации рабочего MVP.
