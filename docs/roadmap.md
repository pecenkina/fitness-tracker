# План разработки Fitness Tracker

## Этап 1 — MVP

- [ ] Проектирование структуры PostgreSQL и API.
- [ ] Инициализация frontend (React, TypeScript, Vite, PWA).
- [ ] Инициализация backend (ASP.NET Core).
- [ ] Регистрация, вход и профиль.
- [ ] Каталог упражнений и фильтры.
- [ ] Создание тренировок, подходов и журнал.
- [ ] Шаблоны и запуск тренировок по планам.
- [ ] Графики силового прогресса и распределение мышечной нагрузки.
- [ ] Проверка адаптивности, авторизации и установки PWA.

- [ ] Расширенная аналитика и фильтры.
